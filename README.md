# Power-vs-Devils
a funny 2D shooting game
Power vs Devils is a a funny 2D graveyard arena shooter where you play as Power or  Aki ( 2 different characters ) depending on your choice  .
The playable character blast lasers either with a cat or a gun towards their target that are the Devils ( NPC coded to kill the User if they touch you )
SO here is our Github link to try the game ;) 
it was  built in Godot Engine using GDScript . And the main problems we faced were our lack of knowledge and expertise in this engine because we weren't familiar with it enough and the time that was given was too tight . 
.It was designed without using any AI , we drew the characters and the backgrounds ourselves .
For full transparency, AI (Gemini and Chat Gpt ) was used purely as a learning guide to understand Godot's workflow and debug GDScript code to     .
